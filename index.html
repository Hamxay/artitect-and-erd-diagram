Sequence Flow Diagrams

📄 Invoice Creation & Delivery Flow
User
Frontend
API
Worker
S3
Email
1 User → Frontend: Create new invoice
2 Frontend → API: POST /invoices (status: DRAFT)
3 API → Database: INSERT invoice with org_id, client_id
4 User → Frontend: Add line items and totals
5 User → Frontend: Click "Issue Invoice"
6 Frontend → API: POST /invoices/{id}/issue
7 API: Generate invoice_number, set status=ISSUED, locked=true
8 API → Worker: Enqueue PDF generation job
9 Worker: Fetch invoice data, render PDF template
10 Worker → S3: Upload generated PDF
11 Worker → API: Update invoice.pdf_url with signed URL
12 User → Frontend: Click "Send to Client"
13 Frontend → API: POST /invoices/{id}/send
14 API → Email: Send email to client with PDF link
15 Email → Client: Invoice email delivered ✅
💳 Payment Webhook Processing Flow
Client
Stripe/PayPal
Webhook
API
Worker
1 Client → Stripe: Complete payment via Stripe checkout
2 Stripe: Process payment successfully
3 Stripe → Webhook: POST payment.succeeded event with signature
4 Webhook → API: Forward webhook payload
5 API: Verify webhook signature (HMAC-SHA256)
6 API: Check idempotency (provider_ref uniqueness)
7 API → Database: INSERT payment record
8 API: Get FX rate if currency differs
9 API → Database: UPDATE invoice amount_paid
10 API: Update status to PAID or PARTIAL
11 API → Worker: Enqueue receipt email job
12 Worker: Send receipt & update reporting
🧮 Monthly Tax Calculation Flow
Cron
API
Database
FX API
Worker
1 Cron → API: POST /tax/recalculate?period=2025-09
2 API → Database: SELECT tax_profile for org
3 API → Database: SELECT paid invoices in period
4 API: Loop through each invoice
5 API → FX API: GET exchange rate for date
6 API: Convert to base_currency & sum gross income
7 API: Calculate taxable_income = gross - deductions
8 API → Database: SELECT tax_rates for country & year
9 API: Apply progressive tax slabs
10 API: Apply exemptions from profile
11 API → Database: INSERT tax_calculation with breakdown
12 API → Worker: Enqueue notification if threshold exceeded
13 Worker → User: Send email with tax summary
